第一次設定（約 2 分鐘，每台裝置貼一次同一組 token）：
1. GitHub 右上角頭像 → Settings → 最下面 Developer settings → Personal access tokens → Tokens (classic)。
2. Generate new token (classic) → Note 隨便填（例如 cv-consult）→ Expiration 建議選 90 days 或 1 year。
3. Select scopes 只勾「gist」這一項，其他都不要勾 → Generate token。
4. 複製那串 ghp_ 開頭的字（離開那個頁面就看不到了）→ 貼到上面欄位 → 按「連結並同步」。
5. 其他裝置（家裡電腦、手機）打開同一個網址，貼同一組 token 即可。
紀錄會存成你帳號底下一個「私密 Gist」，只有你自己看得到。token 只存在這台瀏覽器；公用電腦用完請按下面的「離開這台電腦」。
